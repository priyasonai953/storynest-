TinyTales Day 2 Add-on

This is a CONFLICT-FREE add-on package. It intentionally does not contain replacement files named index.html, style.css or script.js.

It can safely live beside the existing TinyTales files in GitHub.

IMPORTANT: Adding a folder alone does not automatically load JavaScript in an existing webpage. The existing page must explicitly load the add-on script. Do not delete or replace the existing ZIP/code because of this add-on.
